# Community standards

Swift-Mermaid welcomes contributors with different backgrounds and levels of
experience. Discuss ideas respectfully, provide reproducible evidence, respect
others' privacy and accessibility needs, and avoid harassment, discrimination,
threats and unwanted contact.

The maintainer may moderate harmful content and restrict participation using
GitHub's moderation tools. For a public moderation concern, open an issue without
repeating sensitive details; use GitHub's report-abuse controls for private
concerns. Report security problems as described in [SECURITY.md](SECURITY.md).
