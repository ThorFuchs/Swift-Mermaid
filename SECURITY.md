# Security policy

Security fixes target the latest release. Older releases do not receive
backports.

Please report suspected vulnerabilities privately through [GitHub's private
vulnerability reporting](https://github.com/ThorFuchs/Swift-Mermaid/security/advisories/new).
Do not include exploit details in a public issue. Include the package and OS
versions, the affected API, and a minimal input and reproduction. If private
reporting is unavailable, use GitHub's private contact or report-abuse tools
rather than publishing sensitive details.

The [security model](Documentation/SECURITY-MODEL.md) describes the safeguards
and their limits. If the problem also affects the pinned Mermaid version,
consider reporting it upstream using Mermaid's security policy.
